**Building practical software for security, infrastructure, public safety and research.**

Ashmere Software develops open-source and proprietary projects with an emphasis on security, privacy, maintainability and real-world operation.

## Projects

### Project S.W.A.N.
**Scientific Wildlife Acoustic Network** — privacy-first passive acoustic wildlife monitoring and research.

### Kestrel CAD
Modern computer-aided dispatch and MDT tooling for online public-safety communities.

### Kestrel Sentinel
Security monitoring, detection, investigation and controlled response across hosts and applications.

### Beacon
Lightweight, self-hosted service and infrastructure monitoring.

## Engineering principles

- Security by design
- Privacy-aware data handling
- Least privilege
- Strong tenant and trust boundaries
- Reproducible deployments
- Useful observability
- Clear rollback paths
- Automated testing plus independent security challenge
- Open source where appropriate

## Contributing

Public projects welcome useful issues and contributions. Please read the organisation contribution and security guidance before opening a pull request.

**Security vulnerabilities must be reported privately.**
